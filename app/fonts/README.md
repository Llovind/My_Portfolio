# Local fonts

- `Geist-Variable.woff2`: body/story type, weights 100–900; `OFL-Geist.txt`.
- `EBGaramond-Regular.woff2`: narrative display type; `OFL-EBGaramond.txt`.
- `JetBrainsMono-Regular.woff2`: Hero labels; `OFL-JetBrainsMono.txt`.

Loaded using `next/font/local` through `story-fonts.ts` and `hero-fonts.ts`. No font download is needed at build time or runtime. The Hero name retains its approved native/system font stack and kerning.

Files originated from existing licensed local Next.js/preset assets. Keep the files and their SIL Open Font Licenses together when redistributing source.
